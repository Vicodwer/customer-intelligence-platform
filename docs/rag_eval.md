## How relevance is judged

A retrieved complaint is relevant to a query if its CFPB product and issue category equals the category the query was written for. Queries were written after reading about 8 complaints from each category.

Each query is tagged by how consistent its category is: **strong** (most sampled complaints match the question), **mixed** (about half), **weak** (few), **broad** (a very large category, where almost any retriever scores well).

## Limits of this evaluation

- Categories are chosen by the person filing the complaint, so they are noisy. A retrieved complaint can be a good answer and still be scored wrong.
- Queries were written by the project author, not collected from real users.
- One query per category (two where a category splits in half) gives a small sample. Treat differences of a few points as noise.
- `random P@k` is the precision you would get by picking complaints at random, so `lift` shows how much better than chance the retriever is.
